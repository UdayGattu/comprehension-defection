# ---------------------------------------------------------------------------
# WHY THE PINS ARE LOAD-BEARING
# ---------------------------------------------------------------------------
# CLAIMS.md B5, "Measured causal effects shift with the inference stack", is a
# result of this study, not a caveat about it. Re-running the identical exp3
# design on the exp4 stack at full N:
#
#     ATE_true      (arm 3 vs arm 3b)   replicated to ~0.002
#     perturbation  (arm 1 vs arm 3b)   llama_sem allc  -0.1806 -> -0.2218
#
# A 4pp shift on identical inputs. The block-vs-block contrast is stack-robust;
# the block-vs-no-block contrast is not. So "which stack" is an experimental
# factor here. Changing a version below without recording it makes any new
# number incomparable with the corpus, and the failure is silent.
#
# The environment actually in force is written to `run_meta` on every run
# (vllm_version, torch_version, transformers_version, driver, gpu_name,
# python_version, git_commit). Read it from the database rather than trusting
# this file for any run you did not launch yourself.
#
# ---------------------------------------------------------------------------
