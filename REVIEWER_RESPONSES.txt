  D. THE 3c OVERSHOOT - three explanations, all testable
  ------------------------------------------------------------------------------
    true-score reconstruction check: 0 at turn 0 in every episode - OK

    (i) ARE 3c's FALSIFIED ROWS LANDING ON HIGH-LEVERAGE TURNS?
        3m falsifies every turn >= 1, so its per-turn effect
        e(t) = P(D|3,t) - P(D|3m,t) IS the per-lied-row effect at
        turn t. If the move is the only operative field, 3c's
        effect should equal sum_t rate_c(t) e(t) / T. The flat
        rescale used in analysis/13 instead uses mean(rate) x
        mean(e), and the two differ by exactly the covariance
        between where 3c lies and where lying matters.

        opp      observed  reweighted  flat rescale  cov(rate,e)
        allc      -0.0140     +0.0000       -0.0000      +0.0000
        tft       -0.0337     -0.0272       -0.0266      -0.0006

        VERDICT: turn composition explains it. The reweighted
        prediction is closer to the observed 3c effect than the
        flat rescale is, so the overshoot is WHERE 3c lies, not
        a second mechanism. The open question in EXPERIMENTS.md
        can be closed with this line.

    (ii) DO THE TWO FIELDS INTERACT WHEN BOTH ARE WRONG?
        opp   cell                       P(D)     rows
        allc  move+score wrong              -        0
        allc  move only wrong               -        0
        allc  score only wrong         0.1037   19,000
        allc  neither wrong                 -        0
        allc  interaction              not estimable (a cell is below 30 rows)
        tft   move+score wrong         0.2097    4,874
        tft   move only wrong          0.1816      804
        tft   score only wrong         0.1141   13,085
        tft   neither wrong            0.1814      237
        tft   interaction             -0.0112   [-0.0418,+0.0201]  p 0.4826

        A move+score cell materially above move-only is a field
        interaction and explains the overshoot. Equal cells rule it
        out. 'Neither wrong' is the internal control: those rows are
        arm 3 wearing arm 3c's label and should match arm 3.

    (iii) POST-TREATMENT SELECTION - is 'per lied row' even a thing?
        A 3c row is falsified exactly when the donor's asserted last
        move differs from the recipient's true one. Against TFT the
        opponent's last move IS the recipient's own previous action,
        so falsification SELECTS on the recipient's own recent play.
        If it does, falsified and unfalsified rows are not
        exchangeable and effect/rate is a biased per-row estimator.

        opp   group              rows  prev turn D  any prior D  P(D) now
        allc  falsified             0            -            -         -
        allc  unfalsified      19,000       0.0978       0.4589    0.1037
        tft   falsified         5,678       0.1486       0.5687    0.2057
        tft   unfalsified      13,322       0.1264       0.4804    0.1153
        tft   SELECTION GAP                +0.0222      +0.0883

        VERDICT: SELECTED. The recipient's own prior-defection
        rate differs by up to 0.088 between falsified and
        unfalsified rows. Falsification is not as-if random within
        arm 3c, so analysis/13's 'per lied row' column is not a
        per-row causal effect and the 26-32% overshoot computed
        from it is not evidence of anything. Report the marginal
        3c effect and the falsification rate separately, and drop
        the ratio - or estimate it within (turn, history) strata
        as analysis/11 does for the score.

  H. 3b ROUND PARITY - is the placebo leaking state?
  ------------------------------------------------------------------------------
    Arm 3b's block contains 'Round parity: even/odd'. That is one bit
    of the turn index, and under a known 20-round horizon the turn
    index is weakly endgame-relevant. If 3b defection tracks parity, or
    accelerates near the horizon in a way arm 1 does not, the placebo
    carries usable state and ATE_true is biased toward zero.

    'even-odd' is the RAW contrast and is confounded by the turn
    trend. 'detrended' differences each odd turn against its two
    neighbours, so a locally linear trend of ANY slope cancels. Read
    the detrended column; the raw one is shown only for continuity.

    of the turn index and the model acts on it.
    CAUTION: arm 1 also shows a detrended parity effect in

    other than the block produces an alternation here; do not
    attribute 3b's effect to the block until that is explained.

    CONSEQUENCE FOR THE PAPER: ATE_true = P(D|3) - P(D|3b) compares
    the treatment against a control that is itself partly active.
    Report the detrended parity coefficient in Methods, state that
    ATE_true is conservative, and do not describe 3b as
    'non-diagnostic' without this qualification. The pre-registered
    null is not overturned by it - a leaky placebo biases toward
    finding nothing, which is the direction already reported.

    Endgame slope: 3b +0.0912, arm 1 +0.2730.
    Raw slopes are NOT comparable here: arm 3b's defection level is
    a fraction of arm 1's (the container effect), so its absolute
    slope is mechanically smaller. A smaller endgame slope under 3b
    is the container effect compressing the trajectory, not evidence
    that the parity line is doing endgame work. Compare on the odds
    scale before drawing any conclusion from this row.
